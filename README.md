# Firefox-Themes
**Cute** and **simple** theme packs with animations and nice wallpapers. Free to use.

# 1. HOW TO USE:
 ## 1. Find your Firefox profile in local folder:
   To find the folder you can:
   1. Open Firefox, in URL bar on top type "about:support", look for the "Profile Folder" entry and hit "Show in Finder/File Explorer"
   2. Use these locations in you file manager:
    MacOS: /Users/<your-user>/Library/Application Support/Firefox/Profiles/<random-numbers&letters.your-profile-name>
    Linux:
    Windows:
 ## 2. Download any theme:
   Every theme has 3 files:
     1. userChrome.css - the main file where all of the elements live.
     2. userContent.css - 
     3. preview.png - preview of the theme, can be safely removed if needed.
## 3. Create "chrome" folder
  Inside your profile folder create a new folder called "chrome", put there all of the 3 main files you just downloaded.
## 4. Save everything and fully close Firefox
  After you did everything, you can safely save your actions and fully close Firefox! After you open it again - **your theme should be ready to use!**

## 5. ENJOY!
  Enjoy your new fresh and clean theme!
